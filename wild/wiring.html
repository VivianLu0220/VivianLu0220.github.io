页面会动 是故意的 The restlessness is deliberate

我脑子里一般同时开着好几件事。有时候是在跑的模型，有时候是还没决定怎么插的一束花，有时候就是噪声。

这个网站也是这么排的。背景一直在动，字会轻微漂，隔几秒会暗一下——那是走神。鼠标靠近的东西会清楚，离远的会糊，跟注意力差不多。

ADHDANXIETYDEPRESSION

这三个词放在这里是背景，不是主题。有的日子页面跑得快，有的日子慢一点，都正常。

简历那页故意做得清楚，招人的人十秒钟能找到要看的东西。其他部分是氛围，不是地图。

技术上：纯静态 HTML，没有框架。背景是一个 canvas 粒子场，颜色随一个 40 秒的周期在色相上转，页面上所有强调色都跟着这个变量走。聊天页后面是一个 Cloudflare Worker 和一个 HF Space。

My head usually has several things open at once. Some of them are a model I'm training. Some are a bouquet I'm still deciding on. Some are just noise.

This site is laid out the same way. The background keeps moving, the type drifts a little, and every few seconds things dim for a moment — that's attention dropping out. Whatever the cursor is near gets sharp; everything else blurs.

Those three are texture here, not the subject. Some days the page runs fast, some days slower. Both are normal.

The CV page is deliberately clear, so whoever is hiring can find what they need in ten seconds. The rest is atmosphere, not the map.

Under the hood: static HTML, no framework. The background is a canvas particle field whose hue cycles over 40 seconds, and every accent colour on the page follows that variable. The chat page talks to a Cloudflare Worker and an HF Space.
